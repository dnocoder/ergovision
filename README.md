# ErgoVision

ErgoVision - готовое web-приложение для анализа посадки пользователя за компьютером. Система работает локально в браузере: получает изображение с веб-камеры, определяет keypoints тела через MoveNet, рассчитывает признаки позы и показывает итоговый уровень риска.

Проект выполнен как финальный MVP для учебного группового проекта по ML/AI systems.

## Возможности

- видео с веб-камеры и наложение ключевых точек, цвет которых зависит от уровня риска;
- pose-estimation на базе TensorFlow.js MoveNet (модель загружается локально или из TFHub);
- демо-режим без камеры: синтетическая поза периодически «сутулится», чтобы показать реакцию системы;
- калибровка нормальной посадки по серии кадров (~1,5 с); калибровка сохраняется между запусками и сбрасывается одной кнопкой;
- признаки позы: наклон головы, перекос плеч, смещение головы, близость к экрану, подвижность;
- индекс риска от 0 до 100, уровни «норма / средний / высокий» и подсказка, что исправить;
- предупреждение, если высокий риск держится дольше заданного времени: баннер, звуковой сигнал и системное уведомление (по желанию);
- пауза оценки, когда пользователя нет в кадре — без ложных «высоких рисков»;
- анализ продолжается в фоновой вкладке;
- статистика текущей сессии: длительность, средний и максимальный риск, доля времени в норме, число предупреждений;
- график риска за последние 3 минуты;
- история сессий в LocalStorage (сохраняется и при закрытии вкладки);
- настройки чувствительности, сглаживания, порога уверенности, частоты анализа и предупреждений — сохраняются между запусками;
- экспорт отчета в JSON;
- адаптивная верстка для ноутбука, планшета и телефона.

## Загрузка модели MoveNet

При `npm install` автоматически запускается `postinstall`-скрипт `scripts/download-movenet.mjs`. Он скачивает MoveNet Lightning в локальную папку `public/models/movenet-lightning/`, чтобы приложение могло запускать pose-estimation без ожидания загрузки модели из TFHub во время демонстрации.

Если локальная модель отсутствует или скачать ее не получилось, приложение попробует загрузить MoveNet из TFHub при запуске.

Если нужно пропустить скачивание модели при установке, например без интернета, в PowerShell выполните:

```powershell
$env:ERGOVISION_SKIP_MODEL_DOWNLOAD='1'
npm install
Remove-Item Env:\ERGOVISION_SKIP_MODEL_DOWNLOAD
```

В Git Bash, Linux или macOS:

```bash
ERGOVISION_SKIP_MODEL_DOWNLOAD=1 npm install
```

Скачать модель вручную после установки можно командой:

```bash
npm run download:movenet
```

Если сеть медленная, можно увеличить таймаут скачивания:

```powershell
$env:ERGOVISION_MODEL_DOWNLOAD_TIMEOUT_MS='120000'
npm run download:movenet
Remove-Item Env:\ERGOVISION_MODEL_DOWNLOAD_TIMEOUT_MS
```

## Как пользоваться

1. Нажмите «Запустить» и разрешите доступ к камере.
2. Сядьте ровно, чтобы голова и плечи были в кадре.
3. Нажмите «Калибровать» и посидите неподвижно 1–2 секунды — эта посадка станет нормой.
4. Работайте как обычно. Если посадка нарушена дольше заданного времени (по умолчанию 10 секунд), появится предупреждение с подсказкой.
5. В «Настройках» можно включить звук и системные уведомления, изменить чувствительность и задержку предупреждения.
6. Нажмите «Остановить» — итоги сессии попадут в историю. Кнопка «Экспорт» скачивает отчет в JSON.

Если камера недоступна (нет устройства, доступ запрещен или страница открыта не по HTTPS/localhost), приложение переключается в демо-режим и сообщает причину.

## AI-компонент

ErgoVision использует готовую browser-based pose-estimation модель MoveNet из `@tensorflow-models/pose-detection`. Модель возвращает keypoints тела, а проектный AI/CV слой рассчитывает собственные метрики посадки.

| Признак | Что показывает |
|---|---|
| Head tilt | Отклонение головы от нормального положения |
| Shoulder tilt | Разницу высоты левого и правого плеча |
| Head offset | Смещение головы относительно центра плеч |
| Distance | Относительное расстояние пользователя до камеры |
| Stability | Насколько сильно меняется поза между кадрами |

Итоговая оценка:

| Risk score | Интерпретация |
|---:|---|
| 0-30 | Нормальная посадка |
| 31-60 | Средний риск |
| 61-100 | Высокий риск |

## Baseline и Improved

| Версия | Описание |
|---|---|
| Baseline | Таймер напоминает пользователю проверить посадку, но не анализирует изображение |
| Improved | AI-модуль анализирует keypoints с камеры и предупреждает только при признаках неправильной посадки |

Польза AI-компонента в том, что система реагирует на фактическое положение пользователя, а не просто на прошедшее время.

## Архитектура

```text
src/
  ai/
    poseModel.ts          # загрузка и запуск MoveNet
    postureMetrics.ts     # расчет признаков посадки
    riskScoring.ts        # итоговый risk score
    poseSmoothing.ts      # сглаживание keypoints и метрик
  components/
    AppHeader.tsx         # шапка и статус
    AlertBanner.tsx       # предупреждение о плохой посадке
    CameraPanel.tsx       # камера, keypoint overlay, калибровка
    MetricsPanel.tsx      # текущие метрики
    RiskGauge.tsx         # индикатор риска и подсказка
    SessionChart.tsx      # статистика и график сессии
    HistoryPanel.tsx      # история сессий
    SettingsPanel.tsx     # панель настроек
    BaselineTimer.tsx     # контрольный таймер без AI
  storage/
    sessionStore.ts       # история сессий в localStorage
    settingsStore.ts      # настройки и калибровка в localStorage
  utils/
    alerts.ts             # звук и системные уведомления
    format.ts             # форматирование времени и процентов
  types/
    pose.ts               # типы pose/result/session/settings
  App.tsx                 # интеграция сценария
```

## Ограничения

- проект не является медицинской диагностикой;
- качество зависит от камеры, освещения и видимости плеч/головы;
- видео не сохраняется и не отправляется на сервер;
- для MoveNet нужен браузер с поддержкой WebGL;
- системные уведомления и доступ к камере работают только по HTTPS или на localhost.
