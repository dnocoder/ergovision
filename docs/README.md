# ErgoVision documentation

Эта папка содержит заполненные markdown-версии проектных таблиц и материалов для защиты.

| Файл | Назначение |
|---|---|
| `project-brief.md` | Паспорт проекта |
| `moscow-mvp.md` | Приоритизация функций и состав MVP |
| `roadmap.md` | Дорожная карта |
| `analogs-analysis.md` | Анализ аналогов |
| `ai-quality-evaluation.md` | Оценка качества AI-компонента |
| `time-estimate.md` | Оценка сроков |
| `cost-estimate.md` | Расчет стоимости |
| `ai-adaptation-checklist.md` | Чек-лист AI-адаптации |
| `pitch-template.md` | Шаблон питча |

Файлы `.docx` в этой папке являются исходными шаблонами и не коммитятся, потому что `*.docx` остается в `.gitignore`.
