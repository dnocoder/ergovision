# Расчет стоимости

| Статья расходов | Месяц MVP | 6 месяцев пилота | 12 месяцев production | Примечание |
|---|---:|---:|---:|---|
| Разработка | 0 BYN | 0 BYN | 0 BYN | Учебный проект команды |
| Frontend hosting | 0 BYN | 0 BYN | 0 BYN | Vercel / Netlify free tier |
| Backend hosting | 0 BYN | 0 BYN | 0 BYN | Backend не используется в MVP |
| База данных | 0 BYN | 0 BYN | 0 BYN | LocalStorage в браузере |
| AI inference | 0 BYN | 0 BYN | 0 BYN | MoveNet работает локально |
| Домен | 0 BYN | 0-50 BYN | 50-100 BYN | Для MVP не нужен |
| Мониторинг / аналитика | 0 BYN | 0 BYN | 0-100 BYN | Можно добавить позже |
| Поддержка | 0 BYN | 0 BYN | Зависит от команды | Для учебного проекта не учитывается |
| Итого | 0 BYN | 0-50 BYN | 50-200 BYN | MVP практически бесплатный |

## Оптимизация стоимости

- выполнять inference локально в браузере;
- не хранить видео на сервере;
- использовать бесплатный frontend hosting;
- хранить историю локально через LocalStorage;
- не подключать платные API для базового MVP.
