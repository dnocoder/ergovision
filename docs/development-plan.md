Заполнить основные поля.

### 2.2. MoSCoW / MVP

#### Must

- Доступ к веб-камере.
- Подключение pose-estimation модели.
- Получение keypoints головы и плеч.
- Расчет базовых признаков позы.
- Вывод текущего статуса пользователю.
- Минимальная оценка качества на тестовых сценариях.

#### Should

- Калибровка нормальной позы.
- Сглаживание значений между кадрами.
- График изменения risk score.
- История сессий.

#### Could

- Настройки чувствительности.
- Экспорт результатов сессии.
- Несколько профилей пользователя.

#### Won't now

- Медицинская диагностика.
- Мобильное приложение.
- Серверное хранение видео.
- Обучение собственной большой CV-модели с нуля.

#### MVP для демонстрации

1. Web-приложение получает видеопоток с камеры.
2. Pose-estimation модель определяет keypoints пользователя.
3. Система рассчитывает базовые метрики посадки.
4. Пользователь видит risk score и предупреждение.
5. Есть eval-set и сравнение baseline/improved.

| Критерий | Baseline | Improved |
|---|---|---|

| Использует камеру | Нет | Да |

## 5. Реализовать AI-прототип

### 5.1. Подключить камеру

Минимальный результат:

- пользователь разрешает доступ;
- приложение показывает видеопоток;
- ошибки доступа к камере обрабатываются.

### 5.2. Подключить pose-estimation

Минимальный результат:

- кадры передаются модели;
- модель возвращает keypoints;
- приложение не падает, если человек не найден.

### 5.3. Вывести keypoints поверх видео

Сначала нужно визуально проверить работу модели, а уже потом писать scoring.

Минимальные keypoints:

- нос;
- левое плечо;
- правое плечо;
- левое ухо;
- правое ухо;
- глаза, если они нужны выбранной метрике.

### 5.4. Обработать проблемные состояния

Нужно предусмотреть:

- камера недоступна;
- пользователь не дал разрешение;
- человек не найден;
- keypoints имеют низкую уверенность;
- поза частично вышла из кадра.

## 6. Реализовать posture metrics

Для MVP достаточно 3-4 метрик.

### 6.1. Shoulder tilt

Показывает перекос плеч.

Базовая идея:

```text
abs(leftShoulder.y - rightShoulder.y)
```

Значение лучше нормализовать относительно ширины плеч.

### 6.2. Head offset

Показывает смещение головы относительно центра плеч.

```text
shoulderCenter = midpoint(leftShoulder, rightShoulder)
headOffset = distance(nose, shoulderCenter)
```

### 6.3. Head tilt

Оценить наклон головы по глазам, ушам или другой устойчивой паре keypoints.

### 6.4. Too close to camera

Приближенно оценить слишком близкое положение пользователя по размеру лица или плеч в кадре.

### 6.5. Risk score

Собрать итоговый показатель:

```text
riskScore =
  shoulderTiltPenalty +
  headOffsetPenalty +
  headTiltPenalty +
  distancePenalty
```

После расчета ограничить диапазон:

```text
0 <= riskScore <= 100
```

### 6.6. Сглаживание

Чтобы результат не прыгал:

- хранить последние 10-30 значений;
- применять moving average или медиану;
- сравнить результат до и после сглаживания.

### 6.7. Калибровка

Пользователь принимает нормальную позу и нажимает кнопку калибровки. Система запоминает базовые значения и оценивает дальнейшие отклонения относительно них.

## 8. Подготовить eval-set

### 8.1. Размер

Минимум:

```text
20 тестовых кейсов
```

Желательно:

```text
25-40 тестовых кейсов
```

### 8.2. Сценарии

Пример распределения:

| Класс | Количество |
|---|---:|
| Normal | 8 |
| Head tilt | 6 |
| Shoulder tilt | 6 |
| Head forward / too close | 6 |
| Difficult cases | 4 |

### 8.3. Пограничные случаи

Добавить кейсы:

- плохое освещение;
- плечи видны частично;
- пользователь немного повернулся;
- камера стоит выше или ниже обычного.

### 8.4. Таблица результатов

Для каждого кейса фиксировать:

| ID | Сценарий | Expected | Predicted | Correct |
|---|---|---|---|---|
| 001 | Normal posture | Normal | Normal | Yes |
| 002 | Shoulder tilt | Risk | Risk | Yes |

Если используются фотографии или записи людей, не добавлять персональные материалы в репозиторий без необходимости и согласия.
