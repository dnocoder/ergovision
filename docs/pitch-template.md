# Шаблон питча

| Часть | Что говорить | Кто говорит | Время |
|---|---|---|---:|
| Проблема | Люди долго сидят за компьютером и часто не замечают неправильную посадку. Это вызывает усталость и дискомфорт. | User 4 | 20 сек |
| Для кого | Проект ориентирован на студентов, разработчиков и офисных сотрудников, которые много работают за экраном. | User 4 | 15 сек |
| Решение | ErgoVision открывается в браузере, анализирует посадку через камеру и показывает risk score. | User 2 | 20 сек |
| Где ИИ | MoveNet определяет keypoints тела, а наш AI/CV слой рассчитывает признаки позы и итоговый риск. | User 1 | 30 сек |
| Baseline | Обычный таймер просто напоминает проверить посадку, но не понимает, как пользователь сидит сейчас. | User 4 | 20 сек |
| Improved | Наша версия реагирует на фактическую позу: наклон головы, перекос плеч, близость к камере. | User 1 | 30 сек |
| Demo | Показать normal posture, head tilt, shoulder tilt, too close, график и экспорт JSON. | User 2 / User 3 | 2 мин |
| Архитектура | React/Vite frontend, TensorFlow.js MoveNet, LocalStorage, JSON export. | User 3 | 30 сек |
| Метрики | Accuracy, Precision, Recall, F1, latency и success rate проверяются на eval-set из 20 сценариев. | User 4 | 30 сек |
| Ограничения | Это не медицинская диагностика; качество зависит от камеры, света и видимости keypoints. | User 4 | 20 сек |
| Итог | MVP готов: запускается локально, анализирует позу, показывает риск и сохраняет результаты. | Все | 15 сек |
