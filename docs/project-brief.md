# Project Brief

| Поле | Заполненное значение |
|---|---|
| Название проекта | ErgoVision |
| Проблема | Пользователи долго работают за компьютером и часто не замечают неправильную посадку: наклон головы, перекос плеч, слишком близкое положение к экрану. Это приводит к усталости, дискомфорту и снижению концентрации. |
| Целевая аудитория | Студенты, разработчики, офисные сотрудники и другие пользователи, которые проводят много времени за компьютером. |
| Пользовательский сценарий | Пользователь открывает web-приложение, разрешает доступ к камере, калибрует нормальную посадку и запускает анализ. Система показывает риск, метрики позы, график сессии и историю. |
| Решение | Browser-based приложение, которое локально анализирует позу через webcam и показывает уровень риска неправильной посадки. |
| AI-компонент | MoveNet pose-estimation через TensorFlow.js определяет keypoints тела. Поверх результата рассчитываются проектные posture metrics и `riskScore`. |
| Вход AI-системы | Кадры с веб-камеры пользователя. |
| Выход AI-системы | Keypoints, posture metrics, risk score, уровень риска и краткое объяснение проблемы. |
| Baseline | Таймер-напоминание без анализа изображения. |
| Improved version | Реальное CV-определение позы и предупреждения только при наличии признаков неправильной посадки. |
| Целевые метрики | Accuracy, Precision, Recall, F1, latency, success rate, средний risk score за сессию. |
| Ограничения | Система не является медицинским инструментом, зависит от качества камеры/освещения и не хранит видео. |
