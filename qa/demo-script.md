# ErgoVision demo script

## 1. Запуск

```bash
npm install
npm run dev
```

Открыть:

```text
http://127.0.0.1:5173
```

## 2. Калибровка

1. Сесть ровно перед камерой.
2. Нажать кнопку калибровки.
3. Объяснить, что baseline нужен, чтобы система учитывала положение камеры и
   нормальную посадку конкретного пользователя.

## 3. Normal posture

1. Сидеть ровно.
2. Показать low risk.
3. Обратить внимание на keypoints и метрики.

## 4. Head tilt

1. Наклонить голову в сторону.
2. Показать рост `riskScore`.
3. Объяснить метрику наклона головы.

## 5. Shoulder tilt

1. Поднять одно плечо или наклониться боком.
2. Показать реакцию risk score.
3. Объяснить сравнение высоты плеч.

## 6. Too close

1. Приблизиться к камере.
2. Показать предупреждение.
3. Объяснить, что система оценивает относительное расстояние по keypoints.

## 7. История и экспорт

1. Остановить сессию.
2. Показать историю.
3. Экспортировать JSON-отчет.
