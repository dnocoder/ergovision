# QA checklist

- [ ] `npm install` проходит без критических ошибок.
- [ ] `npm run build` проходит успешно.
- [ ] `npm run dev` запускает приложение на `http://127.0.0.1:5173`.
- [ ] Главный экран открывается.
- [ ] Demo fallback работает без камеры.
- [ ] Камера запрашивает разрешение в браузере.
- [ ] Keypoints отображаются поверх видео.
- [ ] Калибровка baseline выполняется.
- [ ] Risk score меняется при изменении позы.
- [ ] Настройки открываются и меняют параметры анализа.
- [ ] График сессии обновляется.
- [ ] История сохраняется локально.
- [ ] JSON export скачивает отчет.
- [ ] README содержит инструкции запуска.
- [ ] Demo script проверен перед защитой.
